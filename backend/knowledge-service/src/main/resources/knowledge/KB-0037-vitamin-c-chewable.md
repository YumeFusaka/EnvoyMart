第一章 产品概述
1.1 本品为膳食营养补充剂，主要成分为抗坏血酸（维生素 C）。
1.2 规格为每片含维生素 C 500 毫克，橙味咀嚼片剂型。
1.3 本品不能替代药物治疗疾病。

第二章 适宜人群
2.1 新鲜蔬果摄入不足的成年人。
2.2 需要补充维生素 C 的成年人。

第三章 用法用量
3.1 成人推荐每日 1 片，咀嚼服用。
3.2 中国居民膳食指南建议成人每日维生素 C 摄入量为 100 毫克，可耐受最高摄入量为每日 2000 毫克。
3.3 长期超量服用并无额外收益，反而增加不良反应风险。

第四章 相互作用与注意事项
4.1 维生素 C 可促进非血红素铁的吸收，与铁剂同服有助于补铁效果。
4.2 每日摄入量长期超过 1000 毫克时，可能增加草酸钙肾结石风险，有肾结石病史者慎用。
4.3 大剂量维生素 C 可能干扰血糖、便隐血等部分化验结果，体检前应告知医师。
4.4 本品为咀嚼片，服用后建议漱口，减少对牙釉质的影响。
4.5 对本品任一成分过敏者禁用。

第五章 贮藏与保质期
5.1 密封，置于阴凉干燥处保存，避免阳光直射。
5.2 未开封保质期为 24 个月。
5.3 本品易吸潮，开封后请拧紧瓶盖。

第六章 售后与退换
6.1 未开封且外包装完好的本品支持七天无理由退货。
6.2 一经拆封不支持无理由退货，质量问题除外。
6.3 片剂出现开裂、霉变、异味的属于质量问题，可凭照片申请退换。
