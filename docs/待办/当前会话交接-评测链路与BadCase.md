## D5 实现目标

### 智能助手点踩

- 点踩绑定单条 `assistantMessageId`，不保存整个长会话。
- 用户可选择固定原因、多选当前回答附近的关联消息、填写可选说明。
- 服务端从历史消息读取权威 `ChatResponse` 快照，保存回答、对应用户问题、明确选择的消息和完整执行快照。
- 管理端提供 Bad Case 列表、详情、审核状态和加入/移出追加测试集；审核通过的样本进入独立追加 fixture，评测时单独统计并保留来源 `badCaseId`。
- 独立 Redis key；与聊天历史相同 TTL；同一用户/回答幂等更新；支持撤销但不物理删除。
- 必须做会话/消息归属校验、字段长度校验、脱敏和失败日志。

### 检索评测页

逐条默认折叠，展开显示：原始 query、最终 query、HyDE、角度改写、三路候选数、融合数、重排状态、最终 evidence、排名、图谱命中、caseId、耗时和版本信息。快照没有字段时明确显示“未记录”，不能用当前运行结果补历史。

### 回答评测页

逐条默认折叠，展开显示：问题、完整回答、工具轨迹、检索 trace、扩写、证据、引用判定、证据门、根因、requestId、用量、延迟和版本信息。明确区分未执行、执行无结果和历史未记录。
