```
docs/
  ├─ 项目总览.md                     ← 长期资产
  ├─ 平台改造规划.md                  ← 改造事实源（批次表 + 验收证据）

  ├─ 演示数据设计.md
  ├─ 检索效果对照实验结果.md           ← 评测数字
  │
  ├─ 待办/                           ← 目前任务
  │    ├─ 待办总表.md                 ← 本文件，唯一入口
  │    ├─ 统一改动清单.md              ← 执行顺序（G1–G10，按依赖排）
  │    ├─ 评测页真实链路改造.md
  │    ├─ 商品文档强绑定设计.md
  │    └─ 实测问题清单.md
  │
  └─ 归档/                           ← 已完成
       ├─ 下阶段实施计划.md
       ├─ 下阶段优化规划.md
       ├─ 改造进度.md
       ├─ 优化任务执行清单.md
       ├─ 待优化清单.md
       └─ 规划能力评测.md
```

**执行顺序以 `统一改动清单.md` 为准**——它按依赖排（G2 → G3 → G4 是串行关键路径）。
