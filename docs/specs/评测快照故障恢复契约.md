# 评测快照故障恢复契约

目标：当前评测文件损坏或版本不兼容时，保留明确错误状态，同时只读展示最后一份可核验的已完成历史结果。适用于检索、回答质量和管理员运行中心；页面读取不触发模型。

- current 的 `status/runId/snapshotPath/snapshotError` 始终描述当前文件，恢复不能把错误伪装成 `COMPLETED`。
- `lastCompleted` 独立携带历史报告、原 runId、原生成时间和历史文件路径；没有合格历史时为 null，仍展示当前错误。
- 只枚举配置目录直接子级的本类型历史文件；拒绝符号链接、临时文件、错类型、未知版本、非完成态、文件名与 runId 不匹配、无合法写入时间及不可映射的历史报告。按外壳写入时间选最新有效结果，不用文件修改时间推断评测时间。
- 旧版无外壳 current 保持原有兼容读取；历史恢复仅信任带类型、版本、runId、写入时间的外壳。恢复不重写 current 或历史文件，不补造旧评测的字段。
- 保持历史先写、current 后原子替换的顺序；替换中断不会丢失原 current 或已完成历史。失败日志记录当前状态与恢复 runId，不记录模型正文。

验证：`EvalSnapshotStoreTest` 固定损坏/版本不兼容恢复、坏历史跳过、无历史空错误、可信路径边界和 current 替换中断；服务测试断言外层错误与内层旧报告身份独立。`verify-eval-snapshot-fallback-ui.mjs` 使用浏览器 mock 检查三页旧 runId、生成时间和当前错误同时可见，并阻断所有真实评测 POST。后端测试由主代理在源码稳定后统一 Maven 执行，前端执行现有 type-check 和目标 ESLint。
