# T1 审批恢复授权与医学可见事实核验

日期：2026-10-11。状态：实现与确定性回归已完成，新产物真实Redis、跨重启及模型验收待执行。

## 已复现缺口

审批执行租约原为15分钟，首次确认签名仅10分钟。首次接受后进程崩溃，租约到期时签名已经过期，原批次没有可接管的恢复窗口。医学审核原来直接分析Markdown源码；`**9000** IU`的数值单位被格式拆散，同片中的维D上限2000IU也能被错误借给铁。

## 审批契约

- 首次确认仍在原签名10分钟窗口内，过期且从未接受的签名不能写。
- 新签名同时包含接受后恢复时长`r=86400`秒。确认卡明确展示“10分钟内首次确认，接受后24小时内可继续原操作”。时长从接受时刻计算，不从签发时刻提前扣除。
- 首次接受在同一账本CAS中保存`acceptedAt`与`recoveryUntil=acceptedAt+r*1000`。接受时刻不得晚于签名`e`允许的秒精度边界。查询与续租不延长恢复授权。
- 执行租约为30秒。过期旧owner不能续租；新owner仅在原批次、用户与会话、签名、账本、恢复期限均有效且未取消删除时显式接管。每项写动作开始前再次核验。
- 过期签名只能配合此前已接受且完整的独立恢复账本写入，不能凭签名自身扩大写权限。普通确认与MCP入口仍校验首次签名期限。
- 老签名缺少`r`，不自动获得24小时恢复权；首次确认和接受后恢复只在原`e`期限内允许，过期后只查回执。
- 恢复沿用原token、operationId与参数；已提交步骤只重放首次回执，不接续模型任务。超过30秒的旧调用可能仍在下游运行，数据库操作回执保证同operation不重复，新owner不能把无回执当成未执行。
- 缺失或篡改恢复期限、接受时间或原消息身份时，拒绝写权限并保留只读权威查询。
- 后续确认卡仅在原owner完成CAS成功后发布；发布Lua同时校验原CONFIRMED账本、会话墓碑与单次发布位。CONFIRMED不可被回执查询降为UNKNOWN，取消或换owner导致完成CAS失败时，不落盘或返回任何后续可确认token。

验收采用真实签名与共享可控时钟：签发后第599秒接受仍取得完整24小时窗口；崩溃后31秒接管；签名过期但有效接受账本恢复；未接受过期拒绝；24小时截止、取消、删除、旧owner及慢调用竞争均不得新增越权写入。

## 医学契约

核验对象是界面可见事实：内联强调、代码与链接标签不能拆掉实体、数值、单位或否定词；URL目标、代码内和转义后的编号不能冒充平台引用。规格豁免仍只基于真实成功工具的同一商品规格，不豁免医学结论。

数值必须与同一引用切片中的实体和剂量角色对应。推荐摄入量、上限、服用量与规格含量不可互借；同片包含多个实体也不能互借数字。不做未给出的单位换算、剂量推理或跨切片拼补。铁、钙等基本营养素的摄入问法进入医学审核。

数值断言同时核对显式人群条件（成年男性、成年女性、备孕、孕期、儿童、年龄界限等），真实铁摄入资料中的12/18/25毫克不得跨人群互借。复合主体采用实体集合，“钙与铁”不能只核最后一个实体。明示的未知主体、裸主体后接逗号及未知/已知并列主体均保留；同时、建议、根据资料等话语前缀只剥离前缀，不能吞掉其后未知主体。空主体与未知角色不匹配任意source；省略主体只能继承回答同段上一条已核验事实中的明确主体，不得从source唯一实体猜填。说明书标题仅用于确定source自身主体。风险/吸收方向与否定绑定到局部实体关系，不能借同片另一实体的“增加风险”；“有出血风险”“提高风险”同样进入事实分母并要求有效引用。

确定性回归包括分拆Markdown数值、错误单位、内联否定、隐藏URL编号、同片跨实体、推荐与上限错位，以及对应合法事实防误拒。冻结历史答案不修改；判定基线变化须逐句说明，指标只覆盖实际样本，不推断总体医学错误率。

## 冻结答案逐句审计

2026-10-11冻结24条原答案和证据完全保留。相较本次修复前的严格基线，事实分母47、引用检查36不变；未支撑13→16、错误引用8→11。新增三处拒绝，其中G-05的一处为：

> 该产品规格为每粒400IU，资料建议正常成人每日推荐摄入量为400IU。[1][2]。

原切片[1]含每日推荐400IU，原切片[2]含每粒400IU，但没有同一切片同时支撑CONTENT与RECOMMENDED两项。即使数值相同也不能借一个角色证明另一个角色；若分成两句并分别引用对应片段，则两句均可保留。这里固定拒绝结果，不能修改冻结答案使指标变绿。

另外两句分别是G-05“每日总摄入量建议不超过2000IU[1]”和G-14“长期超过2000IU/日应在医生监测下进行[2]”。数值可在原片段中找到，但回答本句没有明确主体，前一医学事实又未通过核验，不能凭source里的维生素D名称填补回答主体。G-05累计2拒、G-14累计3拒；G-08保持0拒、G-18保持1拒。该口径是冻结旧答案的严格重放，不代表当前模型质量；新模型必须另跑真实评测。

G-08的“建议取一平勺，约30克”曾在开发回归中被误当成营养素RECOMMENDED摄入量；它实际是DOSE取用量，原片段“取一平勺，约30克”同角色支撑。修正角色定位后保留原G-08结果0未支撑、0错误引用，并添加每粒含量与每日用量同句共存的正反例，防止整句角色互借或过拒。
